
# 1장-2. 엔터티(Entity)

## 1. 엔터티의 개념

> **엔터티(Entity)** 란 업무에서 관리해야 하는
> 고유하게 식별 가능한 객체 또는 개념의 집합이다.

- 데이터베이스에서 관리하는 **정보의 주제**
- 하나 이상의 속성(Attribute)으로 구성
- 여러 인스턴스(Instance)의 집합

**예시**

- 쇼핑몰: 고객, 상품, 주문
- 학교 시스템: 학생, 교수, 강의

### 1.1 엔터티, 인스턴스, 속성

| 구분 | 의미 | 예시 |
|---|---|---|
| 엔터티 | 관리 대상의 집합 | 학생 |
| 인스턴스 | 엔터티에 속한 개별 데이터 | 학번 1001인 학생 |
| 속성 | 엔터티를 설명하는 특성 | 학번, 이름, 학과 |

**관계형 데이터베이스와 비교**

- 엔터티 ≒ 테이블(Table)
- 인스턴스 ≒ 행(Row)
- 속성 ≒ 열(Column)

※ 논리적 모델의 엔터티가 물리적 테이블과
항상 1:1로 대응하는 것은 아니다.

---

## 2. 엔터티의 특징

엔터티는 다음과 같은 특징을 가진다.

1. **업무 관련성**
    - 업무에서 필요하고 관리해야 하는 정보의 집합
    - 실제 업무 프로세스에서 사용되어야 함

2. **식별 가능성**
    - 각 인스턴스를 유일하게 식별할 수 있어야 함
    - 고유한 식별자(Identifier)가 필요

3. **인스턴스의 집합**
    - 영속적으로 존재하는 인스턴스의 집합
    - 모델링 원칙상 2개 이상의 인스턴스를 전제

4. **속성의 존재**
    - 반드시 하나 이상의 속성을 가져야 함
    - 속성은 엔터티의 특성을 표현

5. **엔터티 간 관계**
    - 일반적으로 다른 엔터티와 하나 이상의 관계를 가짐
    - 단, 통계성·코드성 엔터티 등은 관계 생략 가능

---

## 3. 엔터티의 분류

엔터티는 다음 두 가지 기준으로 분류한다.

- **형태에 따른 분류:** 유형, 개념, 사건
- **발생 시점에 따른 분류:** 기본, 중심, 행위

### 3.1 형태에 따른 분류

| 구분 | 특징 | 예시 |
|---|---|---|
| **유형 엔터티** | 물리적인 형태가 있으며 지속적으로 활용 | 학생, 교수, 강의실 |
| **개념 엔터티** | 물리적 형태는 없지만 관리해야 하는 개념 | 학과, 강의 |
| **사건 엔터티** | 업무 수행 과정에서 발생하는 사건이나 행위 | 수강신청, 출결 기록 |

**핵심 구분**

- 유형: 실제로 존재하는 물리적 대상
- 개념: 형태가 없는 추상적인 대상
- 사건: 업무 수행으로 발생한 사건

### 3.2 발생 시점에 따른 분류

| 구분 | 특징 | 예시 |
|---|---|---|
| **기본 엔터티** | 독립적으로 생성되고 다른 엔터티의 기반이 됨 | 학생, 교수, 학과 |
| **중심 엔터티** | 기본 엔터티로부터 발생하고 업무의 중심 역할 수행 | 개설 강좌 |
| **행위 엔터티** | 두 개 이상의 엔터티 사이의 업무 행위로 발생 | 수강신청, 출결 이력 |

#### ① 기본 엔터티 (Key Entity)

- 업무에 원래부터 존재하는 정보
- 다른 엔터티에 의존하지 않고 생성 가능
- 고유한 주식별자를 가짐
- 다른 엔터티의 부모 역할

#### ② 중심 엔터티 (Main Entity)

- 기본 엔터티로부터 발생
- 업무 처리의 중심적인 역할
- 다른 엔터티와의 관계가 많음
- 데이터 발생량이 많은 편

#### ③ 행위 엔터티 (Action Entity)

- 두 개 이상의 부모 엔터티로부터 발생
- 업무 진행에 따라 데이터가 추가되거나 변경
- 지속적으로 데이터량이 증가하는 경향

---

## 4. 핵심 암기 정리

### 엔터티의 특징

- 업무에서 관리하고 사용되는 정보
- 고유한 식별자
- 2개 이상의 인스턴스 집합
- 속성의 존재
- 다른 엔터티와의 관계

### 엔터티 분류

| 분류 기준 | 종류 |
|---|---|
| 형태 | 유형 / 개념 / 사건 |
| 발생 시점 | 기본 / 중심 / 행위 |

> **시험 포인트**
>
> 사건 엔터티와 행위 엔터티는 서로 다른
> 분류 기준에 속한다.
>
> 하나의 엔터티가 사건 엔터티이면서
> 행위 엔터티일 수도 있다.

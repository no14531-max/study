# 데이터베이스 정규화

**정규화(Normalization)**는 데이터 중복을 줄이고 삽입·수정·삭제 이상을 방지하도록 테이블 구조를 나누는 과정입니다.

## 정규형 비교

| 정규형 | 핵심 조건 | 공부 포인트 |
| --- | --- | --- |
| 제1정규형(1NF) | 각 속성 값이 원자값 | 한 칸에 여러 값을 넣지 않기 |
| 제2정규형(2NF) | 1NF를 만족하고 부분 함수 종속 제거 | 복합키의 일부에만 종속되는 속성 확인 |
| 제3정규형(3NF) | 2NF를 만족하고 이행 함수 종속 제거 | 일반 속성 사이의 종속성 확인 |

## 예시

다음 테이블에서 `학생ID`가 학과 정보를 결정하고, `학과ID`가 학과명을 결정한다고 가정해 봅니다.

| 학생ID | 학생명 | 학과ID | 학과명 |
| --- | --- | --- | --- |
| 1 | 민수 | CS | 컴퓨터공학 |
| 2 | 지연 | CS | 컴퓨터공학 |

`학생ID → 학과ID → 학과명` 관계가 있으므로 학생 테이블과 학과 테이블을 분리하면 학과명 중복을 줄일 수 있습니다.

!!! warning "시험 포인트"
    정규화는 **중복 최소화와 이상 현상 방지**에 도움이 됩니다. 다만 조인이 늘어날 수 있으므로 성능 요구사항에 따라 비정규화가 검토되기도 합니다.
